# DeepFilterNet (libDF) compiled to wasm

Built by `scripts/build-deepfilternet-wasm.sh` from https://github.com/Rikorose/DeepFilterNet (commit `d375b2d`,
MIT OR Apache-2.0, see the license files here), with `wasm-pack --target web` and without the embedded default model.
The model itself is `model/DeepFilterNet3_onnx.tar.gz`, unchanged from that repository.

Do not edit these files by hand: rerun the script.
